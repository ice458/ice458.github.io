RPN35 — 逆ポーランド関数電卓 (頒布版)

ice458 / 2025年09月24日 — 電子工作・電卓

自作RPN関数電卓 (別紙) の後継機。演算コアを自作18桁BCDライブラリから Intel® Decimal Floating-Point Math Library (decimal128 / 内部34桁) へ、 MCUをRP2350へ刷新し、2行×16桁LCDの筐体に変数メモリ・キー操作マクロ・多段Undo・Resumeを搭載した。 消費電力は増えたものの、電源は先代同様に単4乾電池1本のみ。

基本仕様

  • 入力方式: RPN (逆ポーランド) / スタック: X, Y, Z, T の4段
  • 表示: 2行×16桁キャラクタLCD (下段X / 上段Y)
  • キー: 5×7の35キー + 電源キー / シフトによる2面配置
  • 計算範囲: ±1×10−6143 〜 ±9.99…9×106144 および0 (実数のみ)
  • 内部計算桁数: 34桁 / 表示桁数: 最大32桁 (符号・指数部含む)
  • 角度単位: DEG / RAD / GRAD、入力文字数上限: 40文字
  • 変数メモリ: A〜Fの6個 / マクロ: 3スロット×各1024イベント
  • 科学定数: 2グループ×10種 (CODATA 2022) / サイズ: 約100×62×10mm
  • 電源: 単4乾電池1本
  • 消費電力 @1.5V: 約7.5mW (入力待ち) / 約18mW (動作時)

演算コア: decimal128

先代では十進演算のためにBCDライブラリを自作したが、本機では Intel® Decimal Floating-Point Math Library を採用した。 内部34桁・指数範囲10−6143〜106144という仕様は IEEE 754-2008 の decimal128 そのもので、 二進浮動小数点のような「十進で有限桁の値が内部で循環小数になる」問題が原理的に発生しない。

固定小数桁表示 (Digits 0〜9) では銀行家の丸め (round-half-to-even) を用い、丸め方向の偏りによる累積誤差を避けている。

Undo / Resume

Last キーの動作は設定で Last X / Undo を切り替えられる。 Undo側では最大100ステップの多段Undo (スタックのみ) が可能で、マクロ再生後にUndoすると実行前の状態まで一括で戻る。 Resume はOFF時にスタック・変数・Last Xを保存し、次回起動で復帰する。

変数メモリとマクロ

変数はA〜Fの6個。ST/LD/CLR で変数操作モードに入り、 変数キーを押すと操作が実行されて抜ける (ロードは変数キー直接押下でも可)。

マクロはキー押下イベントの記録・再生であり、数値入力のキー操作も記録される。 このため、標準にない定数をワンアクションで入力させる用途にも使える。

ファームウェア更新

更新はRP2350のUF2機構で行う (BOOTSELを押しながら電源投入 → USBマスストレージに .uf2 をコピー)。 ファームウェアはPico C SDKとIntel DFP Math Library (3条項BSD) を利用。
